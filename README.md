# Статус продвижения КЦОД

Страница отчёта о продвижении контейнерных ЦОД производства АйТек.
Выкладывается сюда, чтобы её можно было открыть по ссылке без учётных записей.

- `index.html` - последний выпуск отчёта заказчику, он же адрес по умолчанию.
- `ГГГГ-ММ-ДД/index.html` - архив выпусков, каждый остаётся на своём адресе.
- `plan/` - план продвижения на 30, 60 и 90 дней: все слои, а не только реклама.
- `zadanie/` - разбор кабинета Яндекс.Директа и задание исполнителю по шагам.

Исходник живёт во втором мозге: `projects/aitek-ktsod-growth/reports/status-kcod.html`.
Числа берутся из API Яндекс Директа, Метрики (счётчик 111347702) и Вебмастера.
Страницы закрыты от индексации поисковиками.
